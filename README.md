# Fisha · فيشة

نظام تحكم محلي وسحابي ذكي لمشتركات الطاقة **LG U+ MTTL-W01** عبر وحدة تحكم **ESP32 Hub** وتطبيق أندرويد متكامل مبني بفلاتر (Flutter).

---

## الإصدار الجديد · Version 2.0.1

### 🚀 تحديثات الفيرموير (ESP32 Hub Firmware v2.11):
- **استقرار فائق وعدم التعليق:** حل جذري لتهنيج الهاب عند إغلاق التطبيق أو قفل الشاشة عبر بث SSE غير حاجز بمهلة 80ms.
- **تنبيهات مشفرة بدون تأخير:** نقل إرسال إشعارات `ntfy` المشفرة عبر HTTPS إلى مهمة خلفية مستقلة (FreeRTOS Background Task) لمنع تجميد المعالج أثناء مصافحة TLS.
- **حماية وضع التشغيل الدائم (`keepOn`):** ضمان استمرار تشغيل المخارج المحمية حتى لو أُغلقت باقي المخارج أو انقطع التطبيق.
- **اتصال محلي للمستخدمين المدعوين (Local Access for Shared Users):** دعم التحقق وتمرير التوثيق محلياً عبر الشبكة المنزلية بدون الاعتماد على السحابة للمستخدمين المشاركين.
- **إعادة اتصال ذكية بالواي فاي:** إعادة الربط التلقائي بالشبكة المحلية في الخلفية دون الحاجة لإعادة تشغيل الهاب (Reboot).

### 📱 تحديثات التطبيق (Android App v2.0.0):
- **حماية متكاملة للفولت والأمبير:**
  - سلايدر تحديد أدنى فولت (180V–220V) وأعلى فولت (225V–270V) للمشترك ككل.
  - سلايدر تيار مخصص ومستقل لكل مخرج (0–16A) مع دعم التيار في الأتمتة والسيناريوهات.
  - حركة ناعمة وسلسة جداً في كافة السلايدرات (الحرارة، الفولت، الأمبير).
  - تنبيه لوني استباقي (Warning Ring) على المخرج عند الاقتراب من حدود الأمان قبل الفصل الفعلي.
- **واجهة مستخدم محسّنة وأنيقة:**
  - تكبير عيون مخارج المشترك وتوزيعها بانسجام وتنسيق أوضح.
  - شريط تنقل سفلي زجاجي عائم (Floating Nav Capsule) مفصول عن حافة الشاشة.
  - زر إضافة عائم مدمج ومحدد.
  - توهج ناعم (Border Glow) يضيء حول كارت المشترك النشط وينطفئ عند إيقافه.
  - نقل أيقونة السجل والتنبيهات إلى الهيدر العلوي بجوار وضع الاتصال.
  - إمكانية نسخ الماك أدرس بلمسة واحدة.
  - دعم اختيار وتعيين أيقونات/إيموجي مخصصة لكل مشترك وغرفة.
  - إصلاح صفحة إعدادات الواي فاي وربط الشبكة.

## بنية المشروع · Project Structure

- `firmware/mttl_hub/` — كود الفيرموير لوحدة ESP32 (الإصدار v2.11) على Arduino core 3.x مع تقسيم Minimal SPIFFS.
- `app/` — كود تطبيق الأندرويد المكتوب بفلاتر (الإصدار v2.0.0). يتم بناؤه ونشره تلقائياً بصيغة APK عبر GitHub Actions في قسم Releases.
- `docs/protocol.md` — توثيق بروتوكول اتصال المشتركات وواجهات برمجة تطبيقات الـ Hub API.
